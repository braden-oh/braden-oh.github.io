PROGRAMMING CHECKLIST PROCEDURE WRITTEN BY SUPERVISOR

Follow these steps to complete the Program Proposal:

1. Fill out the Northwood Program Proposal 2026-2027 Google Form [https://docs.google.com/forms/d/e/1FAIpQLSf1hujZj68LZv7CcCHtgyuSBMZPiBYFJx0rD93P07FHTQw92g/viewform]
Important Note: For collaborative programs, only one RA needs to fill out the Program Proposal Form!
If the form has already been submitted by a team member, skip to Step 2.
Yes! You still have to complete this assignment, even if you were not the person responsible for submitting the form.
2. Navigate to the NW Program Proposals Folder [https://drive.google.com/drive/folders/1dmtOESyYSRshqaAHl9PTgFgp4QJF-HMr], located in Google Drive
3. Find and open the Google Doc associated with your program
Doc names are generated according to the following formula, based on the information entered in the form: <<program date>> <<program title>>
You may also see a PDF copy of your proposal in the folder. Do not utilize the PDF for the purpose of completing this assignment.
4. Review the Program Proposal
Ensure the information in the document is correct; if anything is not correct, you can make changes directly in the document at this time
If this is a collaborative program, all group members should agree on the information included in the proposal (ideally this would be discussed in advance)
5. Copy the complete web address of the correct Google Doc
6. Return to the Canvas Assignment
7. Add the following information into  the assignment text box:
Program Title: [enter title]
Program Date: [enter date]
Collaborating RAs: [enter the names of ALL participating RAs, or enter N/A if this is a solo program]
Link to Proposal: [paste the complete web address of the Program Proposal Google Doc]
Proposal Complete By: [enter the name of the RA who submitted the Program Proposal Form; if this was you, enter your name]
8. Submit the assignment
