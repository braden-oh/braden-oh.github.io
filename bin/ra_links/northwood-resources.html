Program Proposal — Step-by-Step

1
One Person Add the program to the NW Programming Calendar
Open the NW Programming Calendar and create an event for your program.
2
One Person Fill out the Supply Request Sheet
If your program requires supplies, fill out the Supply Request Sheet and enter your program's supply request information. Copy the sheet's URL — you'll need to paste it into the Program Proposal Form in Step 3.
⚠️ Correction: the supply request sheet must be filled out before submitting the proposal form, because the form requires a link to it. Filling it out after (as originally listed) will block form submission.
3
One Person Submit the Program Proposal Form
Complete the Program Proposal Google Form, including the budget sheet link from Step 2. For collaborative programs, only one RA submits this form.
4
One Person Find the auto-generated Google Doc & share it
Open the NW Program Proposal Folder. A Google Doc named [date] [program title] will have been auto-generated by the form. Do not use any PDF copy in the folder — open the Doc, verify the info, and share it with all collaborators.
5
Everyone Review and agree on the Google Doc
All participating RAs should open the shared Google Doc and verify that the information is correct. For collaborative programs, confirm everyone agrees on the proposal details before submitting to Canvas.
6
Everyone Submit the Canvas Program Proposal Assignment
Go to the Program Proposal assignment in Canvas and paste the following into the text box:
  • Program Title: [title]
  • Program Date: [date]
  • Collaborating RAs: [all RA names, or N/A]
  • Link to Proposal: [Google Doc URL from Step 4]
  • Proposal Complete By: [name of RA who submitted the form]
7
Everyone Submit program flyers on Canvas
Each RA must upload the program flyer(s) to Canvas individually. Here's a flyer Drive folder so that you don't have to G-Chat them to each other.
⚠️ Correction: every RA submits flyers separately — not just one person. Don't skip this even if someone else already uploaded theirs.
8
Everyone Update the Program Budget Sheet
If your program requires supplies, fill out the NW Program Budget Sheet.
9
Everyone Log the program in the CD Tracker
Each RA logs their participation in the Community Development Tracker.
